> **Important:** the projects here are **representative of the college assignments**. They are educational works built from the professors' requirements, and are not production-ready products.

This repository gathers the work developed during the program, organized by semester and by course. The goal is to document the progress of my studies and keep the code of each assignment versioned and accessible.
